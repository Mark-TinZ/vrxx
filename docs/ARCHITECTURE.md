# Архитектура проекта Vrxx

Проект построен на базе **GTK4**, **Libadwaita** и **Rust**. 

## Основные компоненты

1. **GTK/Libadwaita (Слой UI)**
   - Взаимодействует с пользователем.
   - Подписан на сигналы и обновляет модели (`gio::ListStore`).
   - Использует `glib::spawn_future_local` для интеграции асинхронных задач в Event Loop GTK.

2. **Backend (Слой сервисов)**
   - Управляет жизненным циклом ядер (Xray/Sing-box) через `std::process::Command`.
   - Запуск и остановка производятся без блокировки UI-потока.
   - Опрашивает статистику (statsquery).

3. **Domain (Слой данных)**
   - Парсинг VPN-ключей (VLESS, VMess, Trojan).
   - Генерация JSON-конфигов для Xray (с использованием `serde`).
   - Сохранение и загрузка настроек приложения.

## Ограничения
- Главный поток GTK **не должен блокироваться** тяжелыми вычислениями или I/O.
- Логирование производится с буферизацией для защиты SSD от износа.
