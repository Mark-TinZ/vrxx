# 08. Локализация

## Обзор

VRXX поддерживает мультиязычность. Для локализации (i18n) используется стандартная в мире Linux и GNOME система **Gettext**, интегрированная в Rust через крейт `gettext-rs`.

## Поддерживаемые языки

| Язык | Код | Статус |
| --- | --- | --- |
| **Русский** | `ru` | ✅ Полный перевод |
| **Английский** | `en` | ✅ Полный перевод |

По умолчанию приложение использует настройку `"system"`: язык интерфейса автоматически определяется на основе системных переменных окружения (в порядке приоритета: `LANGUAGE`, `LC_ALL`, `LANG`). Пользователь может принудительно выбрать русский или английский язык в Настройках.

## Структура файлов локализации

Все файлы переводов хранятся в директории `po/`:

| Файл | Описание |
| --- | --- |
| `vrxx.pot` | Шаблон всех переводимых строк в проекте (Portable Object Template). Генерируется из исходного кода. |
| `ru.po` | Файл перевода на русский язык. |
| `en.po` | Файл перевода на английский язык. |
| `LINGUAS` | Текстовый файл со списком поддерживаемых языковых кодов (один на строку). |
| `POTFILES.in` | Список файлов исходного кода (Rust и XML), в которых утилиты gettext должны искать строки для извлечения. |

## Как работает Gettext в VRXX

1. **Исходный код**: В коде приложения строки оборачиваются в макрос или функцию `gettext("Hello")`. В XML файлах интерфейса (`.ui`) добавляется атрибут `translatable="yes"`.
2. **Извлечение**: Утилита `xgettext` проходит по файлам из `POTFILES.in` и собирает все строки в шаблон `vrxx.pot`.
3. **Перевод**: Переводчики копируют шаблон в файлы `.po` и заполняют переводы.
4. **Компиляция**: Во время сборки приложения (`cargo build`), скрипт `build.rs` вызывает утилиту `msgfmt`, которая компилирует текстовые `.po` файлы в бинарный формат `.mo` (Machine Object). Они сохраняются в папку `locale/{lang}/LC_MESSAGES/vrxx.mo`.
5. **Рантайм**: При запуске `main.rs` вызываются функции `bindtextdomain` (указывает путь к папке `locale`) и `textdomain` (указывает имя домена, в нашем случае `"vrxx"`). Приложение автоматически подменяет оригинальные строки на переведенные.

## Настройка языка в приложении

Когда пользователь меняет язык в Настройках (например, с `"system"` на `"ru"`), `VRXX` устанавливает системные переменные окружения прямо внутри процесса приложения перед инициализацией GTK:

```rust
// Устанавливаем принудительный язык
std::env::set_var("LANGUAGE", "ru");
std::env::set_var("LC_ALL", "ru_RU.UTF-8");
std::env::set_var("LANG", "ru_RU.UTF-8");
std::env::set_var("LC_MESSAGES", "ru_RU.UTF-8");
```

После этого вызывается `setlocale(LocaleCategory::LcAll, "")`, и интерфейс загружается на выбранном языке.

## Как добавить новый язык

Если вы хотите перевести VRXX на новый язык (например, испанский — `es`):

1. **Создайте файл перевода**: 
   Скопируйте шаблон:
   ```bash
   cp po/vrxx.pot po/es.po
   ```
2. **Переведите строки**:
   Откройте `po/es.po` в текстовом редакторе или специализированной программе (например, Poedit) и заполните значения `msgstr`.
3. **Добавьте язык в конфигурацию**:
   Добавьте код языка `es` отдельной строкой в файл `po/LINGUAS`.
4. **Пересоберите проект**:
   При запуске `cargo build` скрипт сборки автоматически скомпилирует `es.mo` файл.
5. **Тестирование**:
   Запустите приложение с принудительной сменой переменной:
   ```bash
   LANGUAGE=es cargo run
   ```

## Извлечение новых строк

Если вы добавили новый исходный файл (`src/new_file.rs`) с переводимыми строками:
1. Обязательно добавьте путь к этому файлу в `po/POTFILES.in`.
2. Обновите шаблон `.pot` (обычно это делается утилитой `xgettext` или `meson compile vrxx-update-po` при использовании Meson).
3. Синхронизируйте `.po` файлы (через `msgmerge`).
