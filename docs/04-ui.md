# 04. Пользовательский интерфейс

## Обзор

Графический интерфейс VRXX построен на базе `GTK4` и `Libadwaita` версии 1.5+. Это обеспечивает нативный вид приложения в среде GNOME, поддержку системной тёмной темы, плавные анимации, закруглённые углы и адаптивную верстку.

Всё взаимодействие с пользователем локализовано в директории `src/ui/`.

## Структура окна (`VrxxWindow`)

Основное окно приложения наследует `adw::ApplicationWindow`.
- **Заголовок (HeaderBar)**: Содержит кнопку активного подключения со статусом и выпадающим меню (показывает пинг, трафик, геолокацию), а также основное меню (гамбургер).
- **Боковая панель (Sidebar)**: Меню навигации, реализованное через стилизованный `ListBox`.
- **Контентная часть (Stack)**: Контейнер `gtk::Stack`, оборачиваемый в `AdwToastOverlay` для всплывающих тостов, в котором находятся 4 основные страницы приложения. Переключение между страницами происходит с плавной анимацией (crossfade).
- **Адаптивность (`AdwBreakpoint`)**: При ширине окна <600sp боковая панель автоматически сворачивается в компактный режим.

## Страницы приложения

### 1. Страница VPN (`vpn_page.rs` / `.ui`)
Самая сложная и объёмная страница (~66KB кода).
- **Список ключей**: Отображается через `gtk::ListView` (работает поверх `gio::ListStore`), что обеспечивает высокую производительность даже при тысячах добавленных ключей.
- **Пустое состояние**: Использование `AdwStatusPage` при отсутствии соединений.
- **Статистика**: Графическое представление Download/Upload скорости, счетчик длительности подключения.
- **Диагностика**: Кнопка измерения пинга сервера.
- **Импорт**: Из буфера обмена (поддержка ссылок `vless://`, `vmess://`, `trojan://` и `ss://`) или через ручной ввод URL.
- **Скрытие IP (Streamer Mode)**: Кнопка с глазом (в заголовке), которая динамически цензурирует IP-адреса и порты в UI.

### 2. Страница Прокси (`proxy_page.rs` / `.ui`)
Управление портами и локальными подключениями.
- Настройка HTTP и SOCKS5 портов.
- Флажок "Разрешить подключения из локальной сети".
- Интеграция с системным прокси GNOME с безопасным кросс-десктопным фолбэком в KDE/XFCE/Sway (тосты `AdwToast` с предложением включить TUN-режим).

### 3. Страница Белого списка (`whitelist_page.rs` / `.ui`)
Управление правилами маршрутизации пользователя.
- Список доменов, к которым нужно применять особые правила.
- Таблица пользовательских правил (`RoutingRuleObject`): тип (домен, IP, SRS-ссылка), значение и действие (proxy, direct, block).

### 4. Страница Настроек (`settings_page.rs` / `.ui`)
Глобальные настройки приложения и параметры сетевого ядра sing-box 1.13.18+.
- **Структура секций (GNOME HIG 4+)**:
  1. *Общие*: выбор языка, автозапуск в фоне, автоподключение, системные уведомления, режим стримера.
  2. *Сеть и ядро*: прозрачный TUN-режим (gVisor), сниффинг пакетов (SNI/HTTP), блокировка QUIC (UDP 443), обход локальной сети (Bypass LAN), Fake DNS.
  3. *Расширенная оптимизация*: мультиплексирование потоков (h2mux) с настройкой Concurrency (1–128).
  4. *Базы гео-данных*: загрузка и обновление скомпилированных бинарных баз правил GeoIP и GeoSite (`.srs`).
  5. *Тестирование задержки*: выбор алгоритма пинга (TCP Handshake, ICMP Ping, HTTP GET/HEAD via Proxy) и кастомный URL.
  6. *Диагностика и ядро*: версия установленного бинарника sing-box, уровень логирования, окно логов и папка журналов.
  7. *Резервное копирование*: экспорт и импорт настроек и профилей (`ExportBundle` / JSON).
  8. *Опасная зона*: сброс всех настроек и ключей к заводским значениям.
- Все строки снабжены подробными подсказками (`tooltips`) и подзаголовками для удобства пользователей.
- Отслеживание изменений (Snapshot Diff) и кнопка «Применить и перезапустить ядро» (`btn_apply`) с защитой от потери несохраненных данных при навигации.

## Ключевые компоненты

### Окно логов (`log_window.rs` / `.ui`)
Отдельное немодальное окно для мониторинга событий.
- **Многопоточность**: Показывает логи из файлов (`app.log`, `daemon.log`) и из SSE-стрима демона в реальном времени.
- **Функционал**: Фильтрация по уровням логов, поиск по тексту, кнопка автоскроллинга, очистка вывода.

### Интерактивный диалог импорта ключей (`import_dialog.rs`)
Компонент на базе `AdwDialog` (`adw::AlertDialog`), перехватывающий URL-ссылки формата `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` / `hy2://`, `tuic://`.
- **Перехват ссылок**: Регистрация MIME-типов в desktop-файле и обработка сигнала `open` (`gio::ApplicationFlags::HANDLES_OPEN`).
- **Сведения о ключе**: Отображает протокол, хост, порт, параметры безопасности (SNI, Fingerprint, Flow, Public Key).
- **Редактирование**: Позволяет изменить имя профиля прямо в диалоговом окне (`adw::EntryRow`).
- **Асинхронная диагностика**: Неблокирующий замер задержки (TCP Connect Ping) до узла с отображением статуса в реальном времени.
### Интерактивный диалог шеринга и генератор QR-кодов (`qr_dialog.rs`)
Модальный интерактивный диалог на базе `AdwDialog` (`adw::AlertDialog` / `adw::ToastOverlay`), предоставляющий визуальный QR-код профиля VPN для мобильных устройств.
- **Безопасная генерация**: Рендеринг QR-кода выполняется полностью в оперативной памяти в объект `gdk::Texture` без создания временных файлов на диске.
- **Высокая контрастность**: Обертка `card` с гарантированным белым фоном для надежного сканирования камерой в темных и светлых темах оформления GTK4.
- **Копирование ссылки**: Кнопка «Скопировать ссылку» с обратной связью в виде `AdwToast`.
- **Экспорт**: Кнопка «Сохранить QR-код как...» с использованием `gtk::FileDialog` для сохранения в форматах `.png` и `.svg`.

## GLib Object Model


Для привязки данных к виджетам (Data Binding) в GTK4 используются GObject. В `models.rs` определены кастомные объекты:

- **`VpnKeyObject`**: свойства `name`, `protocol`, `is_active`, `is_loading`, `is_error`, `traffic_down`, `traffic_up`, `time_connected`, `ping`, `location`, `url`. Любое изменение свойства автоматически обновляет интерфейс (например, `vpn_key_row.ui`).
- **`DomainObject`**: простое свойство `domain`.
- **`RoutingRuleObject`**: свойства `name`, `rule_type`, `value`, `action`.

## Действия приложения (Actions)

Механизм `GAction` используется для горячих клавиш и команд меню.

| Имя Action | Горячая клавиша | Описание |
| --- | --- | --- |
| `app.quit` | `Ctrl+Q` | Завершение работы программы |
| `app.set-color-scheme` | — | Смена темы (светлая/тёмная/авто) |
| `app.import_config` | — | Загрузка и импорт пакета конфигурации (`ExportBundle`) или `settings.json` |
| `app.export_config` | — | Выборочный экспорт настроек и/или ключей через диалог `ExportDialog` |
| `app.view_logs` | — | Открытие окна логов |
| `app.reset_settings` | — | Сброс настроек (с диалогом подтверждения) |
| `vpn.disconnect` | `Ctrl+D` | Отключение активного соединения |
| `win.zoom_in` | `Ctrl++` | Увеличение масштаба UI |
| `win.zoom_out` | `Ctrl+-` | Уменьшение масштаба UI |
| `win.zoom_normal`| `Ctrl+0` | Сброс масштаба |

## Асинхронные операции в UI

GTK требует, чтобы все изменения UI происходили только в главном потоке.
Для взаимодействия с асинхронными функциями демона используется крейт `glib`:

```rust
glib::spawn_future_local(async move {
    // 1. Асинхронный вызов к Backend
    let result = backend.ping_server(&url).await;
    
    // 2. Безопасное обновление UI в том же главном потоке
    if let Ok(ms) = result {
        key_obj.set_ping(ms as i32);
    }
});
```

Для периодического обновления UI (например, счетчик секунд активного соединения) используется `glib::timeout_add_local`.

## Компиляция ресурсов (GResource)

Файлы `.ui` не загружаются с диска в рантайме. Во время сборки Cargo (скрипт `build.rs`) вызывает `glib-compile-resources`, который упаковывает все `.ui` файлы и иконки прямо в бинарник `vrxx`. Это делает приложение портативным и защищает интерфейс от модификаций.

## Консольный TUI интерфейс (`vrxx tui`)

Помимо графического оболочки (GTK4), VRXX поддерживает интерактивный консольный терминальный интерфейс (`src/tui/`) на базе `ratatui` и `crossterm`.
- Подключается к демону без использования графических компонент.
- Горячие клавиши: `Space` (Подключение), `Tab` (TUN/Proxy), `l` (Логи), `q` (Выход).
- Подробную документацию см. в [09-tui.md](file:///home/mihail/Developer/myproject/vrxx/docs/09-tui.md).
