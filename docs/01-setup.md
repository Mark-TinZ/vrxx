# 01. Установка и запуск

## Назначение проекта

VRXX — это современный, высокопроизводительный графический клиент для VPN-ядра Sing-box, написанный на Rust с использованием GTK4 и Libadwaita. Приложение предоставляет нативный Linux-интерфейс, строго следующий гайдлайнам GNOME HIG, и позволяет легко управлять сложными протоколами (VLESS, VMess, Trojan) и правилами маршрутизации без необходимости ручной правки JSON-конфигураций ядра.

## Способы установки и пакетная матрица

VRXX поставляется в готовых пакетах для всех основных дистрибутивов Linux, строго зафиксированных на стабильную версию ядра **sing-box 1.13.18**:

| Пакет / Дистрибутив | Формат | Способ установки / Сборка |
| :--- | :--- | :--- |
| **Arch Linux / Manjaro** | `PKGBUILD` / AUR | Сборка из исходников через `makepkg -si` в `pkg/arch/` |
| **Debian / Ubuntu / Mint** | `.deb` пакет | `sudo dpkg -i vrxx_*_amd64.deb` (сгенерирован через `cargo-deb`) |
| **Fedora / RHEL / CentOS** | `.rpm` пакет | `sudo dnf install vrxx-*.rpm` (сгенерирован через `cargo-generate-rpm`) |
| **Универсальный архив** | `.tar.gz` | Архив со встроенным бинарником `sing-box 1.13.18`, GUI/TUI, скриптами `install.sh` и `uninstall.sh` |

> [!NOTE]
> **Отказ от Flatpak:** Проект полностью отказался от формата Flatpak ввиду жесткой изоляции песочницы (sandbox), которая препятствует прямому взаимодействию с системным D-Bus, управлению системными TUN-интерфейсами (`/dev/net/tun`), созданию сетевых таблиц маршрутизации ядра и повышению привилегий Polkit.

## Требования к окружению

Для сборки и работы приложения требуются следующие зависимости:

| Зависимость | Версия | Описание |
| --- | --- | --- |
| Rust | 1.80+ | Основной компилятор (устанавливается через rustup) |
| GTK4 | 4.14+ | Библиотеки графического интерфейса |
| Libadwaita | 1.5+ | Виджеты экосистемы GNOME |
| libssl | — | OpenSSL (для сетевых соединений и загрузок) |
| pkg-config | — | Утилита для поиска библиотек C |
| gettext | — | Инструменты локализации |
| **Sing-box** | **1.13.18** | Сетевое VPN-ядро (зафиксировано в релизах) |

## Установка системных зависимостей

В зависимости от вашего дистрибутива, выполните следующие команды:

### Ubuntu / Debian (включая Pop!_OS)
```bash
sudo apt update
sudo apt install libgtk-4-dev libadwaita-1-dev libssl-dev pkg-config gettext polkitd
```

### Arch Linux / Manjaro
```bash
sudo pacman -S gtk4 libadwaita openssl pkgconf gettext polkit
```

### Fedora
```bash
sudo dnf install gtk4-devel libadwaita-devel openssl-devel pkgconf gettext polkit
```

## Сборка из исходного кода

После установки зависимостей, выполните стандартную сборку через Cargo:

```bash
# Клонируем репозиторий
git clone https://github.com/Mark-TinZ/vrxx
cd vrxx

# Собираем релизную версию
cargo build --release
```

Бинарные файлы приложения будут находиться по пути: `target/release/vrxx` (GUI) и `target/release/vrxx-tui` (TUI).

## Запуск и Управление Демоном

VRXX использует двухпроцессную модель с разделением привилегий. Графический интерфейс работает без привилегий (от обычного пользователя), а сетевые операции, требующие настройки TUN-интерфейсов и маршрутов, выполняет привилегированный фоновый демон `vrxx-daemon`.

### 1. Системный сервис systemd (Основной способ)

При установке пакета (`PKGBUILD`, `.deb`, `.rpm` или `install.sh`) создается системный юнит `vrxx-daemon.service`.

Для включения и запуска фонового сервиса выполните:
```bash
sudo systemctl enable --now vrxx-daemon.service
```

### 2. Ручной запуск демона (Для разработки)

Если сервис systemd не установлен, демон можно запустить вручную от `root`:
```bash
sudo ./target/release/vrxx --daemon &
```

### 3. Запуск графического интерфейса

После запуска демона графическое приложение запускается обычным пользователем без вызова паролей `sudo`:
```bash
./target/release/vrxx
```

> **Совет:** Флаг `--hidden` позволяет запустить UI в скрытом режиме (удобно для автозапуска при входе в систему).

## Установка из универсального архива

В релизах VRXX доступен универсальный архив `vrxx-linux-x86_64.tar.gz`:
1. Распакуйте архив: `tar -xzf vrxx-linux-x86_64.tar.gz`
2. Перейдите в каталог: `cd vrxx-linux-x86_64`
3. Запустите скрипт установки: `sudo ./install.sh`
4. Для полного удаления: `sudo ./uninstall.sh`

### Настройка Capabilities (Альтернативный вариант для пакетов)

При подготовке пакетов (`PKGBUILD` в Arch Linux и др.) бинарнику ядра Sing-box могут назначаться права выполнения без полных root-привилегий:
```bash
sudo setcap cap_net_admin,cap_net_bind_service=+ep /usr/bin/sing-box
```

## Сборка через Meson

Meson является альтернативной системой сборки, которая отлично подходит для создания дистрибутивных пакетов.

```bash
# Инициализация сборочной директории
meson setup build

# Компиляция
meson compile -C build

# Установка в систему
sudo meson install -C build
```

## Flatpak

В корне репозитория присутствует манифест `ru.mark.vrxx.json` для сборки Flatpak-пакета.
Пакет использует рантайм `org.gnome.Sdk` версии 50 и расширение SDK `org.freedesktop.Sdk.Extension.rust-stable`.

## Конфигурация и данные

Все пользовательские данные хранятся локально в домашней директории пользователя в соответствии со стандартами XDG:

- **Настройки приложения:** `~/.config/vrxx/settings.json` (права доступа 0600)
- **Защищенное хранилище ключей (AES-256-GCM):** `~/.config/vrxx/data.dat` (права доступа 0600)
- **Логи приложения:** `~/.local/share/vrxx/logs/` (`app.log`, `daemon.log`, `all.log`, `core.log`)
- **IPC Unix Сокет:** `/run/vrxx/daemon.sock` (создается демоном `vrxx-daemon`)
- **Гео-базы данных:** `~/.config/vrxx/geosite.dat`, `geoip.dat` и др.
- **Ядро Sing-box:** `~/.local/share/vrxx/bin/sing-box` (поставляется в готовом релизном архиве или находится автоматически в системе)

## Быстрый старт

### Способ 1: Использование готового релиза (рекомендуется)
1. Скачайте `vrxx-linux-x86_64.tar.gz` со страницы [GitHub Releases](https://github.com/Mark-TinZ/vrxx/releases).
2. Распакуйте архив и перейдите в папку:
   ```bash
   tar -xzf vrxx-linux-x86_64.tar.gz
   cd vrxx-linux-x86_64
   ```
3. Установите приложение и ядро в систему:
   ```bash
   sudo ./install.sh
   ```
   *(Либо запустите `./vrxx` прямо из распакованной папки — ядро `sing-box 1.13.18` подхватится автоматически).*

### Способ 2: Сборка из исходного кода
1. Установите зависимости (см. выше) и убедитесь в наличии `sing-box` версии 1.13.18+ в системе.
2. Соберите приложение и запустите службу демона:
   ```bash
   git clone https://github.com/Mark-TinZ/vrxx && cd vrxx
   cargo build --release
   sudo ./target/release/vrxx --daemon &
   ./target/release/vrxx
   ```
3. Скопируйте ваш VPN-ключ (VLESS/VMess/Trojan/Shadowsocks) в буфер обмена.
4. Нажмите кнопку **"Импорт из буфера"** на главном экране.
5. Нажмите **"Подключить"**. Убедитесь, что индикатор стал зеленым и пошел счетчик трафика.
