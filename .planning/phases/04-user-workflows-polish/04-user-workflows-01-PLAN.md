# Plan 04-01: Импорт ключей и управление конфигурациями

## Цель
Реализовать возможность импорта ключей из буфера обмена и по ссылке (URL).

## Задачи
1.  **key_parser.rs**: Доработать парсинг различных форматов (vless, vmess, trojan, ss) для конвертации в промежуточную структуру.
2.  **vpn_page.rs**: Добавить кнопки "Импорт из буфера" и "Импорт по ссылке".
3.  **backend.rs**: Добавить методы сохранения импортированных ключей в настройки (Settings) без записи на диск в виде временных файлов.
4.  **Валидация**: Проверить корректность парсинга популярных форматов ключей.

## Верификация
- Тест: Импорт корректной ссылки `vless://...` добавляет ключ в список.
- Тест: Ошибка при попытке импорта некорректных данных.
