<task type="auto">
  <name>Task 1: Fix SettingsManager save race condition</name>
  <files>src/settings.rs</files>
  <action>
    - Modify `SettingsManager::save` to perform a synchronous write instead of spawning a thread.
    - Since this is a small JSON file (~1-2KB), a synchronous write is safe and prevents race conditions where the file is read before the write completes.
    - Remove `std::thread::spawn(move || { ... });` and replace with `std::fs::write(&path, content).ok();`.
  </action>
  <verify>
    <automated>grep -v "std::thread::spawn" src/settings.rs | grep "std::fs::write"</automated>
  </verify>
  <done>SettingsManager::save is now synchronous.</done>
</task>
