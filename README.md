# VRXX

Современный, высокопроизводительный графический интерфейс для **Xray-core** и **Sing-box**, созданный с использованием Rust и GTK4/Libadwaita. Разработан с акцентом на приватность, безопасность и соответствие рекомендациям по дизайну интерфейсов GNOME (HIG).

## ✨ Ключевые возможности

- **🚀 Гибридный бэкенд**: Плавное переключение между Xray-core и Sing-box с автоматической адаптацией конфигурации под версию ядра.
- **📊 Живая статистика**: Мониторинг трафика в реальном времени через gRPC (Xray) и Clash API (Sing-box).
- **🛡️ Режим стримера**: Скрытие конфиденциальной информации (IP-адресов, SNI) в один клик для безопасной демонстрации экрана.
- **💾 SSD-Friendly Logging**: Высокопроизводительное асинхронное логирование с разделением на потоки (приложение, демон, ядро) для удобной диагностики и защиты диска от износа.
- **🌍 Гео-сервисы**: Автоматическое определение местоположения сервера, часового пояса и фоновое обновление баз `geosite`/`geoip`.
- **📝 Продвинутая маршрутизация**: Управление кастомными правилами, поддержка форматов `.srs` (для Sing-box) и региональные пресеты (RU, CN, IR, Antifilter).
- **🎨 Нативный дизайн GNOME**: Полное соответствие стандартам Libadwaita 1.6+.

## 🛠️ Требования и зависимости

### Системные зависимости (Linux)
Для сборки проекта требуются следующие пакеты:
- **Rust** 1.80+
- **GTK4** (версии 4.16+)
- **Libadwaita** (версии 1.6+)
- **libssl**
- **pkg-config**
- **gettext** (для локализации)
- **meson** (опционально, для некоторых сборочных скриптов)

### Поддерживаемые ядра
Приложение требует наличия установленных бинарных файлов ядер в `$PATH`:
- **Xray-core**: Версии 1.8.0 и выше.
- **Sing-box**: Версии 1.11.0 и выше (рекомендуется 1.12+ для полной поддержки всех функций).

## 📦 Сборка и запуск

### Установка зависимостей (Ubuntu/Debian)
```bash
sudo apt install libgtk-4-dev libadwaita-1-dev libssl-dev pkg-config gettext
```

### Сборка из исходного кода
```bash
git clone https://github.com/Mark-TinZ/vrxx
cd vrxx
cargo build --release
```

### Запуск привилегированного демона
Для работы TUN-режима приложению требуется запущенный системный демон:
```bash
sudo ./target/release/vrxx --daemon &
```
Затем запустите основное приложение:
```bash
./target/release/vrxx
```

## 📜 Диагностика и логи
Логи теперь разделены по категориям и доступны в консоли настроек:
- `app.log` — Логи графического интерфейса.
- `daemon.log` — Логи системного демона (требуются права root).
- `core.log` — Логи работы ядра (Xray/Sing-box).
- `all.log` — Объединенный поток всех событий.
