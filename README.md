# vrxx

Современный, высокопроизводительный графический интерфейс для **Xray-core** и **Sing-box**, созданный с использованием Rust и GTK4/Libadwaita. Разработан с акцентом на приватность, безопасность и соответствие рекомендациям по дизайну интерфейсов GNOME (HIG).

## ✨ Ключевые возможности

- **🚀 Поддержка нескольких ядер**: Плавное переключение между Xray-core и Sing-box.
- **🛡️ Режим стримера**: Скрытие конфиденциальной информации (IP-адресов) в один клик для безопасной демонстрации экрана.
- **💾 Безопасное для SSD логирование**: Высокопроизводительное асинхронное логирование, которое группирует операции записи для защиты SSD от чрезмерного износа.
- **🌍 Гео-аналитика**: Автоматическое определение местоположения сервера и часового пояса.
- **📝 Продвинутая маршрутизация**: Управление белыми списками с поддержкой подстановочных знаков (например, `*.ru`, `*.google.com`), которые напрямую преобразуются в регулярные выражения для ядра. Поддерживаются правила geosite/geoip.
- **🎨 Нативный дизайн GNOME**: Полное соответствие стандартам Libadwaita, включая поддержку темной темы и адаптивного интерфейса.
- **⚡ Неблокирующий UI**: Асинхронное управление бэкендом гарантирует, что интерфейс никогда не зависает.

## 🛠️ Требования

- **Rust** (Последняя стабильная версия)
- Заголовочные файлы для разработки **GTK4** и **Libadwaita**
- Исполняемые файлы **Xray-core** или **Sing-box**, установленные в вашей переменной PATH

## 📦 Сборка

```bash
# Компиляция и запуск
cargo run --release
```
